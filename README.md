# Бот розыгрышей для MAX

Go + [max-bot-api-client-go](https://github.com/max-messenger/max-bot-api-client-go) + SQLite.

## Запуск

1. В `.env` указать `BOT_TOKEN` и `ADMIN_IDS` (свой id — написать боту `/id`).
2. Заполнить `partners.json` по примеру `partners.example.json`, промокоды положить в `promocodes/`.
3. Запустить:
   ```bash
   go run . load partners.json
   go run .
   ```

Бот должен быть админом канала партнера. Когда его добавят в канал, он пришлет админу `chat_id` для `channel_id`.

## Команды админа

- `/draw ID` — розыгрыш партнера, `/final` — финальный
- `/confirm ID` — разослать уведомления победителям (0 = финал)
- `/winners ID` — список победителей и их данные
- `/give WINNER_ID` — заменить не ответившего победителя следующим резервным
- `/stats` — статистика
- `/send текст` — рассылка

После розыгрыша партнера прием заявок закрывается, после финального — начисление шансов.

Тесты (на фейковом сервере MAX): `go test .`
